# 煤矿安标审核平台设计系统

## 1. 视觉主题与氛围

沉稳、清晰、证据优先的企业审核工具。参考百度智能云解决方案中心的冷白画布、云蓝交互、近黑正文和浅灰分层，但保持审核后台需要的高信息密度。视觉不能抢过客户原文、标准条款和审核结论。

参考 DNA：

- 百度智能云：高纯度云蓝、冷白画布、近黑正文、弱边框、模块化白色内容面板。
- IBM / Carbon：8px 网格、数据密度、平面背景分层和状态语义。

## 2. 色板与角色

- 页面背景：`#F7F9FC`
- 一级表面：`#FFFFFF`
- 二级表面：`#F1F4F8`
- 选中表面：`#EAF2FF`
- 主文字：`#10131A`
- 次文字：`#495366`
- 弱文字：`#818999`
- 主交互：`#2450FF`
- 主交互悬停：`#1B42DF`
- 信息蓝：`#1677FF`
- 成功：`#2E7D5B`
- 警告：`#B56A1B`
- 错误：`#B5453C`
- 边框：`#E4E8F0`
- 焦点环：`rgb(36 80 255 / 20%)`

禁止渐变、纯黑、紫色光晕和大面积深色导航。状态不能只靠颜色表达。

## 3. 排版规则

中文 UI 使用系统字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。

- 页面标题：24px / 600 / 1.35
- 区块标题：16px / 600 / 1.5
- 正文与控件：14px / 400 或 500 / 1.6
- 辅助信息：12px / 400 / 1.5
- 编号、参数和时间：`ui-monospace`，启用等宽数字
- 全部 `letter-spacing: 0`，不用斜体和负字距

## 4. 组件样式

- 全局导航：56px，白底，底部细边框。
- 侧栏：216px，白底；选中项使用整块浅蓝底和云蓝文字，不使用左侧竖线。
- 主按钮：40px，云蓝底色，4px 圆角。
- 次按钮：白底、边框、6px 圆角。
- 输入框：40px，完整边框，6px 圆角，焦点为品牌色外环。
- 数据表：44px 行高，表头浅灰蓝，行悬停整行换底色。
- 状态徽标：小尺寸圆角标签，包含文字或图标，不只显示色点。
- 面板：0-8px 圆角；页面分区优先用背景和分隔线，不把每个区块都做成卡片。
- 浮层：使用蓝色染色多层阴影，仅用于菜单、抽屉和对话框。

## 5. 布局原则

- 4px 基准，主节奏为 8/12/16/24/32px。
- 桌面端固定全局导航与侧栏，内容区自适应。
- 任务列表和标准库优先使用数据表。
- 审核复核页使用三栏：问题队列、原文件、标准依据和人工结论。
- 筛选、标签页和分页写入 URL hash/query，页面刷新后保持。
- 页面只保留一个主操作，次要操作放次按钮或更多菜单。

## 6. 深度层级

- 页面层：`#F7F9FC`，无阴影。
- 内容层：白色或浅灰蓝背景，使用边框分区。
- 浮动层：`0 0 1px rgb(15 48 106 / 20%), 0 6px 18px rgb(45 127 249 / 12%)`。
- 对话框：浮动层阴影加 `rgb(23 43 58 / 24%)` 遮罩。

## 7. Do / Don't

Do：证据定位清楚、状态有下一步、长任务可离开、数据表可扫读、AI结果明确标注来源。

Don't：指标卡堆砌、聊天框作为主界面、深色大屏、AI 紫色、卡片套卡片、左侧竖线选中态、把关键错误藏进 tooltip。

## 8. 响应式

- `>= 1200px`：完整侧栏和三栏复核。
- `768-1199px`：侧栏收为图标模式；复核右栏改可展开侧板。
- `< 768px`：单列任务与只读文档视图；正式复杂审核提示使用桌面端，但仍可确认问题和查看报告。
- 表格窄屏优先保留任务编号、产品、状态和主操作，其他列进入详情。

## 9. Motion 哲学

动效只表达状态和空间关系：按钮 120ms 按压、行 hover 120ms、侧板 220ms、Toast 180ms。使用 `cubic-bezier(.23,1,.32,1)`，禁止 `transition: all`、`ease-in` 和超过 300ms 的 UI 动效。键盘高频操作不做位移动画，支持 `prefers-reduced-motion`。
