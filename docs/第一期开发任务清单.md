# 第一期开发任务清单

## 0. 范围说明

第一期以“可演示的完整闭环”为目标，不追求全部自动化和全部算法精度。
核心边界是：

1. 一个任务对应一个产品和一个型号。
2. 标准和规则分开管理。
3. 执行器由研发实现，管理员只做配置。
4. 历史轮次可复现，快照不可回写。
5. AI 结果可人工修订，局部重跑必须先做影响分析。
