# 第二期生产交付任务清单

## 1. 目标

在不改变第一期主设计原则的前提下，将已完成的功能闭环提升为可部署、可运维、可验收的生产系统。第二期以真实文档处理、真实模型调用、生产前端和端到端交付验证为主线。

## 2. 账户安全与作业控制

- [x] 用户修改密码
- [x] 修改密码后撤销用户全部有效会话
- [x] 待执行作业取消与终态保护
- [x] 密码修改和作业取消操作审计

验收：用户修改密码后所有旧令牌立即失效；管理员只能取消尚未执行的作业，已取消作业不能运行或重试。

## 3. 真实文档处理

- [x] PDF、Word 和 Excel 文本解析
- [x] 扫描件 OCR 与版面坐标保留
- [x] Word 表格行、Excel 工作表和单元格范围证据定位
- [x] 图纸页识别、缩略图和区域证据定位
- [x] 解析失败重试、质量指标和人工修订闭环

验收：上传的技术资料能生成可追溯到页码、区域或单元格的结构化证据。

## 4. 模型接入与智能审核

- [x] 模型密钥可逆加密存储和轮换
- [x] 文本模型与多模态模型统一客户端
- [x] 超时、限流、重试、熔断和调用审计
- [x] 动态原子审核项的真实模型执行
- [x] 证据充分性判定和不可确定结果约束

验收：在不依赖 GPU 的部署环境中，可以通过外部模型完成带证据的审核，模型失败不会破坏任务状态。

## 5. React 生产前端

- [x] 登录、修改密码和会话失效处理
- [x] 任务、文件、轮次和审核工作台
- [x] 标准、规则、执行器和规则包管理
- [x] 问题复核、证据查看和确认式局部重跑
- [x] 报告预览下载、系统配置和运行监控

验收：审核人员和管理员可在生产前端完成各自的核心业务闭环，无需调用 API 或原型页面。

交付记录：`frontend/` 提供 Vite/React/TypeScript 生产前端，覆盖审核人员与管理员路由、真实 API
访问、401 会话失效、密钥不回显和移动端导航。前端通过 TypeScript 生产构建、ESLint 和 8 项组件测试；
Nginx 镜像提供同源 API 代理、SPA 路由回退、上传限制、健康检查和基础安全响应头。

## 6. 生产部署与验收

- [ ] PostgreSQL、Redis、Celery、MinIO 全链路容器验收
- [ ] 数据迁移、备份恢复和对象存储生命周期方案
- [ ] HTTPS、密钥注入、最小权限和安全基线检查
- [ ] 并发审核、队列积压和大文件压力测试
- [ ] 中文 Word/PDF 排版和打印质量验收
- [ ] 监控指标、日志采集、告警通知和运维手册
- [ ] UAT、缺陷收敛和生产发布回退演练

验收：目标部署环境完成安装、迁移、压测、安全检查、业务验收和回退演练，并形成可签署的交付记录。

## 7. 推荐实施顺序

1. 真实文档处理与证据定位
2. 模型密钥管理与统一模型客户端
3. 动态审核真实执行链路
4. React 生产前端
5. 容器全链路、压测、安全和发布验收

| 图纸/页面理解 | 百度千帆 | `ernie-5.0` | `multimodal_chat` |
| 证据向量化 | 百度千帆 | `embedding-v1` | `embed` |

`COAL_MODEL_SECRET_KEY` 独立注入，不能与数据库备份一同保存。普通测试使用假传输，不调用付费接口。
