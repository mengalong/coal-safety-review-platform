## 3. 报告排版验收

验收样本包含任务信息、多个长文本问题和标准覆盖说明。Word 使用 A4 页面、中文字体、页眉页脚、任务
信息表及问题明细表；PDF 使用嵌入式 TrueType 中文字体并生成四页。逐页渲染检查确认：中文可读，
标题、表格与正文无重叠或裁切，长文本正常换行，页眉与页码正确。末页因内容自然结束存在留白，
不属于分页缺陷。

容器镜像内安装文泉驿正黑字体。其他部署方式须设置 `COAL_REPORT_FONT_PATH` 指向可嵌入的 TrueType
中文字体，否则 PDF 生成会明确失败，不产生乱码报告。
